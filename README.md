这是一个基于 Tampermonkey 的自动答题脚本，专为**仲恺农业工程学院实验室综合管理系统**的**题库练习**模式打造。支持自动追踪题目、一键调用 AI 获取解析、纯本地全自动刷题，并自动收录题库。

## 📦 安装方法

1. 确保你的 Edge 浏览器已安装 [Tampermonkey（篡改猴）](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd) 扩展。
2. [点击这里安装脚本](https://raw.githubusercontent.com/CaZaYa/Zk-exam-ai-helper/main/Zk-exam-ai-helper.user.js) 即可。
3. 安装后打开考试系统的**题库练习**页面，右上角会出现操作按钮。

## 💡 使用策略（安全推荐）

本脚本主要针对**题库练习**模式开发。

*   **🚀 题库练习（全自动盲猜纠正）**：
    强烈建议直接使用 **🚀 全自动** 模式。因为练习模式下选错了没关系，脚本盲猜后会自动抓取页面弹出的正确答案并纠正填选，并将题目收录进题库。**纯本地运行，不调用 AI，完全不用担心封禁或风控**。
*   **📥 导出题库（核心玩法）**：
    在练习模式积累了大量题库后，你可以点击“导出题库”。将导出的 JSON 文件“喂”给 DeepSeek（或作为你自己的复习资料），让 AI 提前学习你们的专属题库，大幅提升后续查询的准确率！

## ✨ 按钮功能说明

- **🤖 单题 AI**：调用 DeepSeek 获取当前题目答案，并自动勾选提交（仅建议在练习模式使用）。
- **❓ 仅问 AI**：仅调用 DeepSeek 查询答案，通过弹窗显示结果，不自动勾选选项（适合用来核对或辅助学习）。
- **🚀 全自动**：纯本地暴力破解，先随机盲猜，答错后读取正确答案纠正，自动进行下一题（**刷题神器**）。
- **📥 导出题库**：将后台自动收录的题目、选项、答案导出为 JSON 文件。
- **ℹ️ 关于此物**：内置使用指南与风险提示。

## ⚠️ 注意事项

1. 频繁调用 AI 会触发 DeepSeek 风控，建议被限流时暂停使用 AI 模式，改用本地全自动模式。
2. 题库保存在浏览器本地存储中，**清理浏览器缓存会导致数据丢失，请务必定期点击“导出题库”备份！**
