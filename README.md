# Zk Exam AI Helper

这是一个基于 Tampermonkey 的自动答题脚本，专为**仲恺农业工程学院实验室综合管理系统**打造。支持自动追踪题目、一键调用 AI 答题、纯本地全自动破解刷题，并自动收录题库。

> **🌐 推荐浏览器：Microsoft Edge**
> 强烈建议使用 Edge 浏览器，并前往 Edge 加载项商店安装 **Tampermonkey（篡改猴）** 扩展。其他浏览器由于商店或网络原因，不确定能否顺利安装该扩展。

## 📦 安装方法

1. 确保你的 Edge 浏览器已安装 [Tampermonkey（篡改猴）](https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd) 扩展。
2. [点击这里安装脚本](https://raw.githubusercontent.com/CaZaYa/Zk-exam-ai-helper/main/Zk-exam-ai-helper.user.js) 即可。
3. 安装后打开考试系统页面，右上角会出现操作按钮。

## 💡 适用场景与使用策略（重要）

本系统分为“题库练习”和“正式考试”，请根据场景选择合适的模式：

*   **✅ 题库练习（安全推荐）**：
    强烈建议直接使用 **🚀 全自动** 模式。因为练习模式下选错了没关系，脚本盲猜后会自动抓取页面弹出的正确答案并纠正填选。**纯本地运行，不调用 AI，完全不用担心封禁或风控**。

*   **⚠️ 正式考试（谨慎使用）**：
    建议使用 **❓ 仅问 AI** 模式（前提是你相信 DeepSeek 的正确率）。
    *   **分屏使用**：脚本会为你自动切屏（在考试页和 DeepSeek 之间切换）。
    *   **防作弊警告**：**绝对不要切屏太多次！** 很多考试系统会检测切屏频率，切屏过多可能会被直接判定作弊导致考试不通过。建议分屏显示，或者克制查询频率。

## ✨ 按钮功能说明

- **🤖 单题 AI**：调用 DeepSeek 获取答案，自动勾选并提交。
- **❓ 仅问 AI**：仅调用 DeepSeek 获取答案，弹窗显示，不自动选择（**适合考试**）。
- **🚀 全自动**：纯本地暴力破解，先盲猜，答错后读取正确答案纠正（**适合练习**）。
- **📥 导出题库（核心玩法）**：将自动收录的题目、选项、答案导出为 JSON 文件。
    *   **本质用途**：你可以将导出的文件“喂”给 DeepSeek（例如上传附件或直接粘贴文本），让 DS 提前学习你们的专属题库。这样在未来的“仅问 AI”考试模式中，DS 的回答正确率将大幅提升，甚至直接给出原题答案！
- **ℹ️ 关于此物**：内置使用指南与风险提示。

## ⚠️ 注意事项

1. 频繁调用 AI 会触发 DeepSeek 风控，建议被限流时暂停使用 AI 模式。
2. 题库保存在浏览器本地存储中，**清理浏览器缓存会导致数据丢失，请务必定期点击“导出题库”备份！**
